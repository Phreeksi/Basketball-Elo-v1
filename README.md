I want to work in sports and figured this would be a fun project to solve. This is my first version of this type of analysis, where the goal is to predict winners of each game and roughly how much to bet on each game using Vegas odds. I do not expect this to beat Vegas, but to be a starting point which can be tuned later on. The reason for running an Elo model is like the Bradley–Terry Model, which I have seen in some books like Statistical Sports Models in Excel by Andrew Mack. I, but found that implementing different factors like home-field advantage to be difficult to implement in Python. The data is from Kaggle https://www.kaggle.com/datasets/cviaxmiwnptr/nba-betting-data-october-2007-to-june-2024. This data has all the winners from 2008 to 2025 and has one site betting odds from 2008 to 2023; the rest are missing. Some issues with this analysis that would need to be tuned later on 1. Issue is that I am only simulation the year 2021-2022 and every team starts off with the same Elo rating which is not accurate 2. is that home field advantage is a static value 3. issue is that we only have one value for odds which is not accurate as not all sites have the same odds 4.Ideally, I would want to have all of this data extracted from an API, as well as to automate historical data and all of the odds to be saved in another database for tuning later on.
